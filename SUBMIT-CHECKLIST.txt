⑥ 插件使用说明 *  【支持 Markdown，直接整段复制】
────────────────────────────────
**一键打通 Excel 与多维表格的图片难题。** 官方原生导入会把图片变成 `=DISPIMG("ID_xxx",1)` 文本、导出则图片进不了单元格 —— 本插件解决这两个问题。

## 核心功能

- **图片导入不丢失**：把 Excel 拖进来，里面的图片/视频自动识别并转成多维表格的**附件字段**，字段一一映射到位。
- **图片导出回单元格**：附件里的图片重新嵌回单元格，支持「WPS 嵌入单元格图片」与「标准浮动图片」两种方式。
- **多工作表 / 多图片全支持**：多个 sheet 各自导入为独立数据表；附件有多张图时自动展开为「照片 / 照片2 / 照片3」多列。
- **纯前端、无后端**：所有解析与打包在浏览器本地完成，不上传任何数据到第三方服务器。

## 使用指南

### 导入 Excel

1. 切到「导入 Excel」标签，把 `.xlsx` 等表格文件拖进虚线框（或点击选择）
2. 插件列出文件里所有工作表的字段映射关系，每行是「字段名称 → 字段类型」
3. 按需调整：取消勾选某行 = 不导入该字段；点右侧类型胶囊可换字段类型；点工作表名可折叠或改表名
4. 点右下角「开始导入」，结束后会给出每张表的写入条数

### 导出为 Excel

1. 切到「导出为 Excel」标签，勾选要导出的数据表（可多选）
2. 选图片嵌入方式：
   - **WPS嵌入单元格图片** —— 图片真正待在单元格里，需用 WPS 打开查看
   - **标准浮动图片** —— Excel / WPS / LibreOffice 都能显示，兼容性最好
3. 可选：填「图片边长」等比缩放（留空 = 原图原尺寸）；「全部图片都导出」默认开启
4. 点「导出并下载」

## 常见问题

- **导入后图片列是空的？** 说明文件格式不含图片部件（如 `.xls` / `.csv`），请先用 WPS 或 Excel 另存为 `.xlsx` 再导入。
- **导出后 Excel 里显示公式？** 那是 WPS 的专有扩展，改用「标准浮动图片」模式即可在原生 Excel 里看到图片。
- **会不会写坏原来的表？** 导入是真实写库操作，建议先新建一个空的多维表格试一次。

4. 已用真实 WPS 产出的含图工作簿做过结构比对（test/compare-wps.py），确认写入的图片结构与 WPS 原生输出一致。
5. 本插件为本人（张强）在集团内部工作中自研，用于打通 Excel 与多维表格之间长期存在的"图片无法导入 / 无法嵌入单元格"问题，无商业目的。
